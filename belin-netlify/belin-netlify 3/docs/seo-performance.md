# SEO и скорость BELIN

`npm run build:public` формирует HTML публичных страниц, JSON-LD, адаптивные изображения и версии CSS с хешем. При сборке в Netlify публичный каталог обновляется через существующий серверный обработчик GET /api/public; при отсутствии настроек или ошибке используется проверенный data/public-catalog.json. В fallback нет секретов и заявок. Изменения каталога доступны клиентскому JS сразу с учётом edge-кеша; для обновления поискового HTML требуется новая сборка Netlify.

Главная, услуги, Template и карточка продукта имеют самостоятельные title/description/canonical/OG. ItemList отражает только реально опубликованные услуги и шаблоны. Не добавлены фиктивные отзывы, рейтинги, офисы или несуществующие товарные карточки. 40+ не используется как число реально опубликованных позиций в JSON-LD.

Закрытые страницы имеют noindex в HTML и X-Robots-Tag в Netlify. Не закрывать их одним Disallow: поисковик должен иметь возможность прочитать noindex. robots запрещает служебные API и админку; публичный endpoint явно разрешён. sitemap содержит 4 коммерческие страницы. Демоверсия и известный тестовый клиентский сайт имеют noindex.

Только контентно-адресованные /assets/optimized/* кешируются на год. Старые изменяемые URL не получают immutable. GET /api/public имеет edge-cache 60 секунд и stale-while-revalidate 300; остальные ответы API остаются no-store. CSS объединён с сохранением порядка каскада. Hero srcset 640/1200; ширина и высота заданы, важное изображение имеет fetchpriority=high. Убраны CSS @import цепочки Google Fonts; каталог обнаруживает Inter напрямую через head с preconnect. Неиспользуемый Manrope в светлом редакторе больше не загружается.

Следующий внешний этап: подтвердить https://belin.su/ в Google Search Console и Яндекс Вебмастере, отправить sitemap, смотреть покрытие индекса и реальные Core Web Vitals. Метаданные и sitemap не гарантируют индексацию или позиции. Для роста нужны реальные работы/кейсы, полезные страницы услуг и наполнение Template; не создавать пустые страницы ради ключевых слов.
